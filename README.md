# Horizon Valley - Native Android

Original 2D farming RPG ported to native Java / Android Canvas.

## Features
- Fullscreen landscape gameplay
- Touch D-pad + action buttons
- Farming (hoe, water, plant, harvest)
- Chop trees, mine rocks
- NPCs with simple AI
- Inventory & hotbar
- Day cycle foundation
- Completely native (no Python / no pygame)

## Open in Android Studio
1. Unzip the project
2. Open the folder in Android Studio (File → Open)
3. Let Gradle sync
4. Run on emulator or device (API 24+)

## Controls
- Left virtual pad → Move
- E → Interact / Talk
- I → Inventory
- Run → Hold to run
- Tap ground → Use selected tool
- Back button → Pause / Resume

## Requirements
- Android Studio Hedgehog or newer
- JDK 17
- minSdk 24
